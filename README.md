# NEEDLE — Piercing Studio

Учебный проект для практики HTML, CSS, JavaScript и Git.

## Запуск

Открой `index.html` в браузере или используй Live Server в VS Code.

## Git-практика

```bash
git init
git add .
git commit -m "Первый commit"
```

Создание ветки:

```bash
git switch -c booking-page
```

После изменений:

```bash
git add .
git commit -m "Добавил страницу записи"
```

Переключение обратно:

```bash
git switch main
```

Список веток:

```bash
git branch
```
